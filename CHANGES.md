- **Drum Machine MIDI: 1/16 notes no longer cut, the downbeat no longer lost (CLK SYS)** — recorded in Live, two 1/16 of the same note often came out as a note and a sliver: the gate was 100%, so the first note's note-off landed on the second's note-on and, with a ms of jitter, after it — Live ended the new note at once.
