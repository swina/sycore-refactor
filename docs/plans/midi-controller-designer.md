# MIDI CONTROLLER DESIGNER

The MIDI CONTROLLER DESIGNER is a component that is used to:
- design a controller with the following controls that the user can add to a canvas:
    - pad switch (on/off)
    - pad momentary
    - slider
    - encoder
- each control has MIDI Learn 
- when the controller is designed assign to a MIDI DEVICE 
- the user can then map each control with MIDI Learn
- every designed controller can be saved/loaded later
