# LOOP MACHINE

A new modal with:

- 32 PADS (ON/OFF not switch)
- Each pad can be associated to a freesound or import (wav/mp3/ogg)
- Firing each pad plays the associated sound (sounds can play simultaneosly) as loop (like the LOOP PADS of LivePerformancePad)
- Option: firing a pad start playing when the first fired pad loop start
