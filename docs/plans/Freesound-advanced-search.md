# Add search by category:

- Sound effects
- Music
- Instrument samples
- Soundscapes
- Speech

The query should be:
`?query=music&filter=category:Music`

## Music subcategories:

- Solo instrument
- Solo percussion
- Multiple instruments
- Other

The query should be:
`?query=music&filter=category:Music%20subcategory:"Solo%20instrument"`
