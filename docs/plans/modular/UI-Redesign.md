# UI Redesign
Act as an expert UI/UX Product Designer. I need to redesign the UI/Layout of my application to look highly professional, clean, and modern. 


Design Requirements:
- Visual Style: Clean aesthetic, professional corporate look, premium feel, minimalist but functional.
- Layout: Intuitive information hierarchy, smart whitespace utilization, grid-based alignment.
- Color Palette: 1 primary brand color, 1 accent color for CTAs, and a sophisticated neutral palette (grays/whites for light mode, deep slates for dark mode).
- Typography: High readability, distinct font weight scale for headers, subheaders, and body text.
- Key Elements: Clear visual states (hover, active, disabled), accessible contrast ratios, and cohesive iconography.
- Compatible with tablet devices (minimum requirement)

Deliverables:
Provide on a new main page a comprehensive breakdown of the new layout structure, a recommended design system (colors, typography), and a step-by-step UI wireframe description for the main dashboard screen.
