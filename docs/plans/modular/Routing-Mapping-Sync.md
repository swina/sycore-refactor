# ROUTING - MAPPING - SYNC

Consider that the MIDI Tools to be used to configure the MIDI for the app should be:

- MIDI DEVICES: devices registration
- MIDI FLOW: MIDI routing
- MIDI Controller Designer: to map controllers to app actions
- MIDI Learn: to map specific controllers to app functionalities


All other tools included in MIDI MANAGER should be ignored as configuration in order to simplify the MIDI management.
Maybe a reset of the MIDI Mapping could help to start with a fresh configuration to better understand if there is a problem or not.
