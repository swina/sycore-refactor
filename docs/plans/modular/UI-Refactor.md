# UI Refactor

In order to optimize the user workflow there are some aspects that I would like to fix:

- the main page in a tablet view needs to scrolldown in order to access/view all the options/apps and then select them
- the /workspace UI is ok but the menu accessible from the burger icon has to many icons/apps and it requires a horizontal scrollbar in order to access the app functions
- could be a solution instead of a horizontal menu open a sort of modal with the apps and then add the possibility to mark any app as favorite to create a modal with the preferred apps first 
- in a tablet view most of the apps require a fullscreen view (should be set automatically the max view when a tablet size is recognized) this means that if the user opens more apps the only way to switch windows is to minimize the modal(s) to reopen a previous selected app (also in a normal desktop size monitor). Yes there is the possibility to assign MIDI Controllers (pad,switch) to manage open/close apps modal, but at first use could not be clear to the user of this possibility and in some cases user could not have a controller to use for this scope.

Propose a solution in order to optimize the UI and the user workflow.
