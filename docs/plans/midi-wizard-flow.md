# MIDI WIZARD FLOW

The MIDI WIZARD FLOW should be a drag'n'drop and connect tool with the following features:

1. List of MIDI DEVICES to drag from to a canvas area.
2. Each MIDI DEVICE should have :
    - MIDI IN connector (with a MIDI CHANNEL selector)
    - MIDI OUT connector (with a MIDI CHANNEL selector) to drag a virtual cable to another or more MIDI DEVICE MIDI IN connectors (not itself)
