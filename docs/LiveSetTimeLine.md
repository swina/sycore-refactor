# LIVE SET TIME LINE

Live Set Timeline is intended to create a flow that :
- put in sequence tracks segments (segments are defined using time start/end of a track)
- set markers to register events in the timeline like change performance set, send program change, start/stop step sequencer, start/stop midi clock, change tempo
- a start/pause/stop of the timeline
- a visual rapresentation of the timeline with markers indication, current tempo, track playing (or segment)
